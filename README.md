# SHIFT Commercial Cleaning

A static marketing website for SHIFT Commercial Cleaning. The site is built with plain HTML, CSS, and JavaScript; there is no build step.

## Preview locally

Open `index.html` in a browser, or serve this folder with any static file server. The `industries/` pages and `assets/` directory must remain alongside it so their relative links and images work.

## Deploy

The repository root is the site root. Vercel can deploy it as a static site without a framework preset or build command.

## Demo content

This is a website demo. Confirm business details, pricing, testimonials, service areas, and contact information before using it for a real business. The enquiry form is a front-end demo and does not send submissions to a business inbox.
